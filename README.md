# Archivest — Thought Cabinet & Authorship Station

An ideational atelier engineered for relentless novelists, set in the world of *Disco Elysium*. Built to defend human authorship with dialectical faculties that plan, develop, draft, and audit your manuscript.

## Tech Stack

- **Framework**: Vite + React 18 + TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **Animations**: Framer Motion
- **Icons**: Lucide React, React Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
